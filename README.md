# 모두의 고전 — 여우들의 들판

어린 왕자를 읽고 여우의 마음을 해석해 한 노트북의 들판에 모으는 독후 활동입니다. 별도 설치 없이 정적 웹 서버에서 실행합니다.

```sh
cd /workspace/hey
python3 -m http.server 8000
```

작품은 해당 브라우저의 localStorage에만 저장됩니다. 다른 기기와 동기화되지 않으며 브라우저 데이터를 지우면 사라집니다. 배포할 때 이 폴더를 정적 파일로 제공하면 됩니다. OnPod 배포 절차는 확인되지 않았습니다. 외부 글꼴을 불러오지 못하면 시스템 글꼴을 사용합니다.
